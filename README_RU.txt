
Генератор текста - программа для генерации текста на основе различных алгоритмов.

Описание:
---------
Данная программа позволяет генерировать текст на основе входного текста, 
используя два различных метода:
1. Цепи Маркова - простой статистический метод, который анализирует
   вероятности появления слов после других слов в исходном тексте.
2. LSTM (Long Short-Term Memory) - нейронная сеть, способная учитывать
   более сложные зависимости в тексте и генерировать более связные тексты.

Использование:
-------------
1. Запустите программу text_generator.exe
2. Укажите входной файл с текстом с помощью опции --input или -i
3. Выберите метод генерации с помощью опции --method или -m (markov или lstm)
4. Укажите максимальную длину генерируемого текста с помощью опции --length или -l
5. Для метода LSTM можно обучить модель перед генерацией с помощью опции --train или -t
6. Для сохранения результата в файл используйте опцию --output или -o

Примеры:
--------
text_generator.exe -i input.txt -o output.txt -m markov -l 100
text_generator.exe -i input.txt -m lstm -t -e 5 -l 200

Требования:
-----------
- Windows 7/8/10/11
- Для метода LSTM требуется больше оперативной памяти и процессорных ресурсов

Примечания:
-----------
- При первом использовании метода LSTM с опцией --train программа может работать медленно,
  так как происходит обучение модели.
- Качество генерируемого текста зависит от объема и качества входного текста.
- Для получения лучших результатов рекомендуется использовать большие тексты
  (от нескольких тысяч слов).
